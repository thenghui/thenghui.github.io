
| Course Title:  Enterprise AI Agents with Microsoft Copilot: Build, Optimise & Measure |
| :---- |
| **Overview:**  This 1.5-day hands-on programme equips technical and non-technical professionals to design, build and optimise enterprise AI agents with Microsoft Copilot. Through demonstrations, guided practice and workplace scenarios, participants will learn how Copilot agents retrieve information, generate responses and interact with enterprise systems; how to ground agents in approved enterprise data with Retrieval-Augmented Generation (RAG); how structured prompts and system instructions shape agent behaviour; and how agentic workflows with human-in-the-loop approval support real business processes. The programme concludes with participants building, testing and refining a Copilot agent for a real business use case, then optimising it for reliability, performance, cost and measurable business value. |
| **Target Participants:**  Technical and non-technical professionals involved in building, deploying or using Microsoft Copilot agents. |
| **Learning Outcome:**  By the end of the programme, the participants will be able to: - Explain how Microsoft Copilot agents retrieve information, generate responses and interact with enterprise systems, and identify suitable enterprise use cases. - Design Copilot agents grounded in approved enterprise data using RAG to reduce hallucinations. - Engineer structured prompts and system instructions that improve consistency and guide multi-step reasoning. - Design multi-step agentic workflows with validation, summarisation, decision support and human-in-the-loop approval. - Build and test practical Copilot agent solutions for real business workflows. - Diagnose reliability issues and optimise agent design for performance and cost. - Measure and communicate the business impact of Copilot agents using KPIs and a basic ROI model. |
| **Duration: 1.5 days (in-person)**  Schedule: Day 1, 9:00 AM–5:00 PM; Day 2, 9:00 AM–1:00 PM  |
