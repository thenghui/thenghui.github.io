THE RULE
GitLab is the source of truth. Abacus is a workspace — not a repository.
If it only exists in an Abacus conversation, it is not a project yet.
01

One repo, one skeleton

<project>/ ├── README.md ├── _DOCS/ ├── CurrentStatus.md ├── .env.example └── src/

_DOCS/ = the stable facts. CurrentStatus.md says why.

02

Secrets never in the repo

.env.example in Git — key names, no values.

One key · one owner · one project. Rotate on every departure.

03

“Handed over” = somebody else ran it

Someone who did not write it clones, configures, runs it end to end, changes one thing.

Until then, confidence caps at 6.

04

Session discipline

A new chat per module — flush to CurrentStatus.md first.

Long sessions cost more tokens and drift.
