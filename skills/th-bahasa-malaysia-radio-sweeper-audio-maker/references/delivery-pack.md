# Delivery pack templates

Three markdown files ship next to the audio. Copy these skeletons and fill every `{{...}}`.
Nothing in them may be left as a guess: if you do not know, write "not supplied" and say so.

---

## script.md

```markdown
# {{Station}} — Imaging Sequence, Script and Timing

**Audio:** `{{name}}.wav` (44.1 kHz / 16-bit) · `{{name}}.mp3` (320 kbps)
**Length:** {{66.0}} s · **Bed:** {{118}} BPM, {{A minor}} · **Voice:** {{one persona, Bahasa Malaysia}}
**Voice source:** Gemini 3.8 Flash TTS, designed voice `{{voice_id}}`
**Prepared:** {{date}} · **Status:** demo master for internal review, not a broadcast master

## 1. Sequence
| Timecode | Dur. | Element | What happens | Exit |
| --- | ---: | --- | --- | --- |

## 2. Full script
Per element: timecode block with [BED] / [LOGO] / VO lines, then the exact style string and the
written length.

## 3. Why the read sounds the way it does
| Choice | Reason | Evidence |

## 4. Delivery notes for a human presenter
Numbered, one instruction per line.
```

Rules: quote the **exact** `style` string sent to the model; quote the **exact** text including
tags; keep [Observed] / [Recommended] tags on any claim.

## treatment.md

```markdown
# {{Station}} — Production Treatment

**Master:** `{{name}}.wav` / `.mp3` · {{66.0}} s · 44.1 kHz, 16-bit, stereo
**Prepared:** {{date}}

## 1. Creative intent            ← the three-second test, in plain language
## 2. Voice                      ← model, method, voice ID, persona prompt, language code,
                                   gender + assumption, style strings, post chain
## 3. Music                      ← genre, BPM, key, arrangement map, instrument design
## 4. Designed exits             ← table: exit, timecode, event
## 5. Pacing and transitions     ← element length, ducking, music clearance
## 6. Mix and mastering          ← stage table + measured result table + verification done
## 7. Reproduction               ← copy-paste commands
```

The measured table is mandatory:

| True peak | | ≤ −1.0 dBTP | |
| Loudness range | | — | |
| Sample rate / depth | | — | |

## credits.md

```markdown
# {{Station}} — Credits, Asset Sources and AI Disclosure

## 1. Deliverables               ← table: file, description, format
## 2. Asset sources              ← one row per component, with source and method
## 3. AI disclosure              ← explicit sentence: the voice is synthetic
## 4. Persona and assumptions    ← gender, language code, tempo, placeholders, names removed
## 5. Rights position            ← what is cleared, what is not, broadcast caveat
## 6. Build provenance           ← script → output table
```

Required wording, adapt the nouns but not the meaning:

> **The voice in this demo is synthetic.** It is not a recording of a human presenter and does
> not represent any individual. It was generated by Gemini 3.8 Flash TTS from a written persona
> description.

> **No commercial recordings, samples, loops, jingle melodies or library sound effects were
> used.** No third-party voice was cloned or replicated.

Assumptions table must list at least: gender, language code, script language, tempo, any
placeholder (time check, show name), and anything the client did not supply.

---

## Final checklist

- [ ] WAV and MP3 exist, same duration, MP3 within 0.3 LU of the WAV
- [ ] −16 LUFS ± 0.5, ≤ −1 dBTP
- [ ] `script.md` quotes the exact lines and style strings
- [ ] `treatment.md` has the measured table and reproducible commands
- [ ] `credits.md` states the voice is synthetic and lists the assumptions
- [ ] No invented show, artist, prize, slogan, or audience figure anywhere
- [ ] Old versions removed or archived, so the folder has one current master
